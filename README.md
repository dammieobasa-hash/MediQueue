# MediQueue 🏥

**MediQueue** is a hospital queue management system designed to make waiting for healthcare services more organized and efficient.

The system allows patients to join a queue for a specific hospital service and track their position, while staff can manage and call patients from their department queue.

## ✨ Features

### Patient Side

* Join a queue for a hospital service
* Receive a queue number
* View the current patient being served
* Track your position in the queue
* View the number of patients ahead
* Access different hospital services

### Staff Side

* Staff registration and login
* Staff dashboard
* Select and manage departments
* View department queues
* Call the next patient
* Remove patients from the queue
* Manage patients waiting in the department

## 🚀 Running the Project Locally

1. Install **XAMPP**.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Place the MediQueue folder inside:

```text
C:\xampp\htdocs\
```

4. Open your browser and visit:

```text
http://localhost/MediQueue/
```

5. For the staff section, use the staff login/register pages provided in the project.

## 🎯 Purpose

MediQueue was created as a learning project to practice building a full web application using frontend technologies alongside PHP and database functionality.

The project focuses on creating a simple digital queue experience for both patients and healthcare staff.
